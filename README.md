A professional forensic image analysis tool with advanced UI/UX design.

## ✨ Features

- 📷 **Image Upload** - Drag & drop or click to upload
- 📊 **Basic Information** - Dimensions, size, format, color mode
- 📋 **EXIF Metadata** - Extract camera info, dates, settings
- 📍 **GPS Location** - Show coordinates on interactive map
- 🔐 **Cryptographic Hashes** - MD5, SHA-1, SHA-256, SHA-512
- 🎨 **Color Analysis** - Mean colors, brightness, entropy
- 🔬 **Manipulation Detection** - ELA analysis with warnings
- 🌐 **Reverse Image Search** - Google, Yandex, TinEye, Bing, Baidu
- 📄 **Export Results** - Download JSON or print report

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
- **Libraries:** Pillow, piexif, exifread, OpenCV, folium

## 🎨 UI Features

- Animated particle background
- Glassmorphism design
- Smooth scroll animations
- Interactive hover effects
- Fully responsive
